OpsAgent

The terminal agent that talks to every Ops model. Install once, then type opsss to start. Supports local models and API backends. Browser control via BrowserUSE.

  • Terminal (PowerShell)
  • Local + API
  • Apache 2.0

Beta

Ops 1.0

An open-source and free AI model created by OpsAI. Use it with OpsAgent in the terminal. Currently handles computer data, browser control, and basic tasks — training continues to strengthen capabilities.

  • Open weights
  • Works with OpsAgent
  • Apache 2.0
View Repository

About capability: Ops 1.0 is intentionally positioned as an early beta. It is not yet a frontier model. We are accelerating training so it can do more — please look forward to updates. You can always choose a local model or an API call.
