How to get started

One agent works with every Ops model. Install once, then chat.

  1. 1

    Download OpsAgent

    Visit the opsai-agent/agent repository and grab the required terminal files from the Agent directory.

  2. 2

    Run the installer

    Locate the downloaded files and open install.exe to configure. When it finishes you will see “Install successful.”

  3. 3

    Open a fresh terminal

    Close the current terminal completely and open a new one (a new tab is not enough).

  4. 4

    Start chatting

    Type opsss and begin talking with Ops 1.0 or any other Ops model. Choose local weights or an API key as preferred.

Note: Currently only terminal support is available. A web-based computer-control agent may arrive later. Browser control uses agent360dk/browser-mcp. Models can still be unstable — local or API is your choice.
